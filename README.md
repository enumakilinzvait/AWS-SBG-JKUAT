
# AWS SBG JKUAT

This repository contains the website project for the AWS Student Builder Group (SBG) at JKUAT.

## About the Project

The website will help the group share information about its activities, events, learning resources, and membership opportunities.

## Getting Started

This project uses Next.js.

### Requirements

- Node.js
- npm

### Run the development server

Install dependencies if needed:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

You can start editing the homepage in `app/page.tsx`. Changes will appear automatically while the development server is running.
